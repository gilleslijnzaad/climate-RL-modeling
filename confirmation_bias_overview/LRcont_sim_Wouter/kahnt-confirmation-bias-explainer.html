Conceptual model note · Rescorla–Wagner

Learning more from outcomes that fit an initial belief

A novice-friendly guide to translating Kahnt et al.’s similarity-weighted learning model into a confirmation-biased learning rate based on the distance between reward and a participant’s initial expectation.

Step 1

Start with the ordinary Rescorla–Wagner model

The model stores a current estimate of an option’s value. After seeing a reward, it computes a prediction error: the difference between what happened and what was expected. The value is then moved part of the way toward the reward.

Vt+1 = Vt + α × (rt − Vt)
Vt
Current learned value before trial t.
rt
Reward observed on trial t.
rt−Vt
Prediction error. Positive means “better than expected”; negative means “worse than expected.”
α
Learning rate. At 0 nothing changes; at 1 the value jumps fully to the latest reward.
In the standard model, the same learning rate α is used regardless of whether an outcome agrees with or contradicts the participant’s initial belief.
Step 2

What Kahnt and colleagues added

Kahnt et al. studied generalization between perceptually similar stimuli. A prediction error generated by one stimulus updated not only that stimulus, but also nearby stimuli. The farther another stimulus was from the observed stimulus, the smaller its update.

ObserveA stimulus produces an outcome.

The model calculates the usual reward prediction error.

MeasureCompute stimulus distance.

Similar orientations have a small distance; dissimilar orientations have a large distance.

WeightScale learning by similarity.

A Gaussian function converts distance into a weight between 0 and 1.

G(x′,x) = exp[−(x′−x)² / (2σ²)]

When the two stimuli are identical, their distance is zero and (G=1): the update is fully expressed. As distance increases, (G) approaches zero smoothly. It never becomes negative and does not need clipping. The parameter σ controls the width of generalization.

Figure 1. Gaussian similarity weighting
Larger σ means broader generalization: distant stimuli receive more of the update.

This is the mathematical precedent for fixing the squared-distance exponent at 2. It defines the Gaussian family; 2 is not an additional fitted parameter.

Step 3

Translate the same idea to your experiment

Before learning begins, each participant reports what reward or value they expect on a 1–10 scale. Call this person-specific initial expectation H. You referred to it as a hyperprior. Computationally, it enters the model as an observed participant-level anchor rather than a fitted parameter.

H = participant’s initial expected reward

On each trial, compare the actual reward with that anchor:

dt = |rt − H|

The absolute value makes the mechanism symmetric. A reward three points above H and a reward three points below H receive the same learning rate. This implements your decision not to model positive–negative asymmetry.

Now use Gaussian similarity to scale the learning rate:

αt = αmax × exp[−dt² / (2σ²)]
Vt+1 = Vt + αt(rt − Vt)
Interpretation: outcomes close to H receive a large learning rate and strongly alter value. Outcomes far from H receive a small learning rate and are discounted. That is the confirmation-bias mechanism.

Exactly two fitted parameters

αmax
The maximum learning rate, occurring when reward exactly matches H. Constrain it to 0–1.
σ
The width of confirmation. A small σ means narrow confirmation; a large σ means outcomes farther from H are still learned from.
H
Measured before the task. It is data, not a fitted parameter.
Figure 2. Trial learning rate on the 1–10 reward scale
Move the controls to see how H, αmax, and σ change the model. H is observed; only αmax and σ are fitted.

With H=4, rewards 3 and 5 are equally distant and therefore produce equal learning rates. Rewards 2 and 6 are also paired, and so forth.

Step 4

Gaussian versus hyperbolic drop-off

Both candidates use only two fitted parameters and both stay strictly between zero and αmax. Neither requires clipping. Their main difference is how rapidly they discount increasingly inconsistent rewards.

Gaussian

αt = αmax exp[−dt²/(2σ²)]
  • Nearly flat at distance zero.
  • Decline then accelerates as distance grows.
  • Eventually approaches zero quickly.
  • σ is the width of the confirmation window.
  • Closely parallels Kahnt et al.’s similarity mechanism.

Hyperbolic

αt = αmax / (1 + k dt)
  • Begins declining immediately at distance zero.
  • The decline becomes progressively shallower.
  • Has a long tail: very inconsistent outcomes retain influence.
  • k is the strength of distance discounting.
  • Does not have the same Gaussian-generalization precedent.
Figure 3. Shape comparison at several parameter values
These parameters are illustrative and not numerically equivalent across families.

Solid blue lines are Gaussian; dashed coral lines are hyperbolic. The Gaussian protects learning near H and discounts remote outcomes strongly. The hyperbolic starts discounting immediately but retains a heavier tail.

Which hypothesis does each curve express?

The Gaussian says: “Small discrepancies are treated almost like confirmation, but sufficiently large discrepancies are rapidly discounted.” The hyperbolic says: “Every discrepancy reduces learning immediately, but even extreme discrepancies retain some influence.” Given your stated idea—slow initial drop-off followed by stronger discounting—and the Kahnt analogy, the Gaussian is the more direct primary model. The hyperbolic is a useful two-parameter comparison model.

Step 5

Trial-by-trial implementation

For each participant, record H before learning. For every trial, select the current option value, observe the reward, compute distance from H, calculate the trial learning rate, and perform the usual Rescorla–Wagner update.

import numpy as np

def gaussian_learning_rate(reward, H, alpha_max, sigma):
    distance = abs(reward - H)
    return alpha_max * np.exp(-(distance ** 2) / (2 * sigma ** 2))

def update_value(value, reward, H, alpha_max, sigma):
    alpha_t = gaussian_learning_rate(reward, H, alpha_max, sigma)
    prediction_error = reward - value
    new_value = value + alpha_t * prediction_error
    return new_value, alpha_t, prediction_error

Parameter constraints during fitting

Estimate αmax on (0,1), for example through a logistic transform. Estimate σ as positive, for example through an exponential transform. The resulting trial learning rate is automatically valid and needs no clipping.

0 < αt ≤ αmax < 1

Recommended model comparison

Fit the same observation/choice model with either the Gaussian or hyperbolic learning-rate rule, keeping everything else identical. Compare predictive performance and conduct parameter-recovery and model-recovery simulations before interpreting participant differences. This tests whether the data truly distinguish the two curve shapes.
